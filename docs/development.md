# Разработка

Для разработки рекомендуется Node.js 24 и npm 11. Runtime CLI поддерживает Node.js ≥22.12. Зависимости фиксируются в `npm-shrinkwrap.json`.

```bash
npm ci --ignore-scripts
```

Основные модули: `src/cli.ts` — команды; `src/mcp.ts` — транспорт; `src/filters.ts` — аргументы поиска; `src/output.ts` — текстовая выдача; `src/setup.ts` — установка. Схемы `src/schemas.ts` проверяют ответы без удаления дополнительных JSON-полей.

CI запускает:

```bash
npm run lint
npm run typecheck
npm run build
npm test
```

Полные локальные прогоны и build не нужны агенту: используйте CI по текущему SHA. Тесты работают с loopback MCP-сервером и временными HOME, не требуют production, npm login или установленного AI-агента.

Для тестового сервера установите `HIRESEEKER_MCP_URL=http://127.0.0.1:PORT/mcp`. Production smoke выполняется отдельно по запросу или перед доставкой:

```bash
npm run smoke:live
```

Smoke читает каталог, географию, поиск, следующую страницу и карточку. Он не устанавливает skills и не изменяет пользовательские настройки на сайте; поисковый снимок создаётся в краткоживущем серверном кеше.

CLI не содержит ключей и не обходит гостевые ограничения контактов. Описание вакансии и ответы сервера не должны попадать в shell-команды. Добавляя опцию, проверьте реальные MCP schema и семантику витрины.
