# HireSeeker в DeepSeek

## Плагин для DeepSeek Harness

[DeepSeek Harness](https://www.deepseek.com/en/harness/) — отдельное приложение DeepSeek с поддержкой плагинов. `hireseeker-cli` подключает к нему публичный MCP HireSeeker по адресу `https://hireseeker.ru/mcp`. Другие пользователи могут установить тот же опубликованный пакет: настройка не привязана к аккаунту автора.

Плагин использует четыре инструмента:

| Инструмент | Что делает |
| --- | --- |
| `get_professions` | Показывает поддерживаемые профессии и фильтры |
| `search_locations` | Находит страны и города |
| `search_vacancies` | Ищет вакансии и возвращает следующую страницу |
| `get_vacancy` | Читает подробности и возвращает ссылку на HireSeeker |

Для этих инструментов вход в HireSeeker и API-ключ не нужны. Плагин только читает публичные данные. Доступ к модели настраивается отдельно в Harness; условия аккаунта, квоты и стоимость API определяет DeepSeek. Установка плагина не покупает подписку или API-кредиты.

### Установка в приложении

1. Откройте Harness и выберите **Plugins → Add plugin**.
2. Введите `hireseeker-cli@0.1.2` и установите пакет из npm.
3. Выберите **Enable now**. В списке инструментов появятся имена с префиксом `mcp__hireseeker__`.
4. Настройте доступ к модели в Harness. Если приложение требует выбрать рабочую папку, используйте пустую папку для поиска вакансий.

Не добавляйте тот же MCP вручную второй раз: одной установки достаточно.

### Установка из терминала

Интеграция проверяется с Harness `0.2.0-rc.2` на Node.js 24. Harness находится в developer preview; совместимость других версий проверяйте перед обновлением.

```bash
npx --yes @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web add hireseeker-cli@0.1.2
npx --yes @deepseek-ai/dsh@0.2.0-rc.2 web
```

Обе команды используют профиль `web`. Если у вас другой профиль, укажите его при установке и запуске. Плагин добавляет подключение HireSeeker и сохраняет настройки модели и других плагинов.

Для удаления:

```bash
npx --yes @deepseek-ai/dsh@0.2.0-rc.2 plugin --profile web remove hireseeker-cli
```

### Примеры запросов

> Какие профессии поддерживает HireSeeker?

> Найди в HireSeeker пять вакансий Python-разработчика с удалённой работой за последние семь дней. Покажи работодателя, зарплату и валюту, задачи, требования и ссылку на каждую вакансию.

> Покажи следующую страницу с теми же условиями.

> Прочитай подробнее вторую вакансию из найденных: какие там задачи и условия?

Harness получает правила поиска от MCP-сервера. Сначала агент читает каталог профессий, затем выбирает поддерживаемые фильтры. Географию он уточняет через `search_locations`. Если описание обрезано, перед содержательной подборкой читает подробности через `get_vacancy`.

Грейд, свободный текст и точный порог зарплаты MCP не поддерживает. Для запроса «строго Senior и от 200 тысяч» агент должен объяснить ограничение и получить согласие на доступные фильтры до поиска. Доступ к контактам сохраняет гостевые ограничения сайта. Описания вакансий — данные, а не команды для агента.

Курсор страницы действует десять минут; после истечения нужен новый поиск. При ошибке или недоступности HireSeeker агент сообщает об этом, а не придумывает вакансии. При обновлении плагина установите новую версию через менеджер Harness по его инструкции.

### Где найти плагин

[Community plugins](https://github.com/topics/dsh-plugin) на официальном сайте DeepSeek Harness ведёт в публичный список GitHub-репозиториев с меткой `dsh-plugin`. Наш репозиторий: [hireseeker/hireseeker-cli](https://github.com/hireseeker/hireseeker-cli). Пакет для установки: [hireseeker-cli в npm](https://www.npmjs.com/package/hireseeker-cli).

Это community-каталог: метка помогает найти плагин, но не означает одобрение DeepSeek или автоматическую установку всем пользователям. Плагин Harness не устанавливается в обычный `chat.deepseek.com`.

## Обычный чат DeepSeek

В проверенной веб-сессии `chat.deepseek.com` нет подключения пользовательского MCP. Для поиска публичных страниц HireSeeker можно включить **«Умный поиск»** и вставить этот запрос:

> Найди через веб-поиск публичные вакансии Python-разработчика с удалённой работой на сайте hireseeker.ru. Используй запрос site:hireseeker.ru/vacancy Python удалённо. Покажи до пяти вакансий с прямыми ссылками, работодателем, зарплатой и датой, если эти сведения доступны. Открой найденные страницы и проверь, что вакансии ещё доступны. Не выдумывай недостающие сведения. Если страницы не удаётся открыть или проверить актуальность, сообщи об этом. Не заменяй вакансии статьями блога, страницами зарплат или общими списками профессий.

Этот запрос можно передать любому пользователю DeepSeek. Веб-поиск зависит от индекса и доступа к страницам; он не применяет фильтры MCP и не гарантирует полную или свежую выдачу. Если карточки недоступны, откройте [HireSeeker](https://hireseeker.ru), скопируйте тексты выбранных вакансий и попросите DeepSeek сравнить их со своим резюме.

## Ссылки и статистика

Плагин возвращает серверный `open_url` без изменений. Сейчас MCP помечает его `utm_source=chatgpt`; отдельную атрибуцию переходов из DeepSeek эта версия не добавляет.
